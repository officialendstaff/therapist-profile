# 予約チャット試作（未公開・開発用）

このブランチは既存の採用・面接・出勤管理に影響させずに、5店舗共通の予約チャット画面を検討するためのものです。

## 確定している運用
- 5店舗でCTIv2の顧客データは共通管理。CTIv2と自動連携しない。
- 来訪者は登録不要で問い合わせを開始できる。
- 予約時に店舗が名前（偽名可）・携帯番号を確認する。
- 新規顧客は店舗が電話番号へ電話して確認し、予約を成約する。
- 既存顧客はスタッフがCTIv2で電話番号を照会し利用履歴を確認する。
- スタッフはチャット表示名を「田中様｜090-...」等へ変更できるようにする。
- 同じ有効なチャット利用資格情報がある場合は表示名を引き継ぐ。
- 保存情報喪失時は新規問い合わせとして扱い、予約時に再度名前・電話番号を聞く。

## この画面の実装範囲
- URLクエリ store で5店舗を切替。
- 登録不要のメッセージ入力、画面内表示、試作用ローカル履歴。
- 実送信・DB保存・管理者対応・本人識別・電話番号登録・通知は**未実装**。
- 試作の履歴はブラウザ localStorage のみに保存。実名や電話番号を入力してはいけない。

## 本番に必要な追加実装（未着手）
1. 顧客用匿名セッション・安全な長期トークン・喪失時の新規扱い
2. 新しいチャット専用DBテーブルと厳密なRLS、送信制限、CAPTCHA
3. スタッフ用認証と5店舗共通管理画面、表示名編集、未読管理、通知
4. 同一チャットの継続利用・返信のリアルタイム反映と履歴保持
5. データ保持期間・プライバシー表示・監査・バックアップ
6. 店舗HPへの設置可否確認（店舗ごとのサイト管理者とドメイン/CSP）
7. 本番環境での端末・Safari・アプリ内ブラウザ・二重返信・アクセス権テスト

重要：ブラウザ端末識別は本人確認を保証しない。登録済み表示名だけで予約者本人であると断定しない。
